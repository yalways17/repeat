# Repeat · 健身打卡

🏋️ 一个只管「今天练什么」的力量训练打卡应用。

按星期自动推送当天计划，练到哪算哪 —— 不必全部点亮。

## ✨ 功能

* 📅 **自动识别周几** —— 打开就是当天的计划，其他天看不到也点不了
* ✅ 每组一个按钮，勾一下即可，进度自动存在本机
* 🏁 **完成训练 / 提前结束** —— 按钮文案跟着进度走，不要求全部点亮
* 🌙 周五 / 周六 / 周日 显示休息日，底部记录栏整条隐藏
* 📝 当天训练备注
* 🗂️ 训练历史（百分比 + 备注），可逐条删除
* 🌗 浅色 / 深色 / 跟随系统
* 💾 进度与备注本地保存，刷新不丢
* ☁️ 云端账户与数据同步
* 🔐 注册 / 登录后跨设备同步进度与历史
* 📱 响应式移动端界面

## 🗓️ 训练计划

| 星期 | 部位 |
| --- | --- |
| 周一 | 胸 · 三头 |
| 周二 | 背 · 二头 |
| 周三 | 功能性循环 |
| 周四 | 肩 · 手臂 |
| 周五 – 周日 | 休息 |

计划写在 `index.html` 的 `plans` 数组里。`todayPlanIndex()` 按 `day` 字段名反查星期，
不写死顺序 —— 想加练，往数组里补一条 `day: '周五'` 就行，其他代码不用动。

跨天时当天的勾选会自动清零（`resetDay()`），所以上周练满的进度不会留到下周。

## ☁️ 云端

数据存在 Supabase，两张表都开启了行级安全（RLS），每人只能读写自己的行：

| 表 | 用途 |
| --- | --- |
| `fitness_state` | 每人一行，整份进度存在 `state` jsonb 里（`upsert` + 900ms 防抖写入） |
| `fitness_history` | 每条训练一行（星期 / 部位 / 百分比 / 备注 / 时间） |

**未登录也能完整使用** —— 数据只存本机；登录后自动同步，并会把本机已有进度迁移上云。
首次登录时如果云端还没有记录，本机进度会先上传，不会白练。

HTML（单文件）+ Supabase（邮箱登录与云端同步）
